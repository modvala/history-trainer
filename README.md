# Тренажёр по истории

Адаптивный тренажёр по истории для 6 класса сербской школы (Рани средњи век, §5–8): вопросы с выбором ответа, рассказ при ошибке, повтор слабых мест и перепроверка угаданных ответов. Интерфейс для ребёнка на сербском, раздел «За родитеље» и отчёты для родителя на русском.

Сайт: https://modvala.github.io/history-trainer/

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Сам тренажёр |
| `bank.md` | Банк вопросов (копия «Банк вопросов.md» из проекта «История», 100 вопросов) |
| `config.js` | Адрес скрипта Google для отправки результатов и токен |
| `setup/apps-script.gs` | Скрипт для Google-таблицы: принимает результаты, пишет в таблицу, шлёт письмо, дописывает MD-файл на Диске |

## Как обновить вопросы

Замените содержимое `bank.md` (тот же формат: `### Q001 | Факт F01 | Тема: … | Уровень: 1`).
Если первые вопросы банка остались прежними, прогресс сохранится. Если банк новый, прогресс начнётся заново.

## Как включить отправку результатов (один раз, около 10 минут)

1. Создайте новую Google-таблицу, например «История — результаты».
2. В таблице: **Расширения → Apps Script**. Удалите всё в редакторе и вставьте код из `setup/apps-script.gs`. Сохраните.
3. В списке функций вверху выберите **setup** и нажмите **Выполнить**. Google попросит разрешения (таблица, почта, Диск): разрешите.
   Если появится «Google не проверил это приложение», нажмите «Дополнительно → Перейти к проекту». Это ваш собственный скрипт.
   Придёт тестовое письмо, и на Диске появится файл «История — результаты.md».
4. **Развернуть → Новое развертывание** → тип **Веб-приложение**.
   «Запуск от имени»: **Я**. «У кого есть доступ»: **Все**. Нажмите «Развернуть» и скопируйте адрес, который заканчивается на `/exec`.
5. Впишите этот адрес в `config.js` в поле `resultsUrl`.

Проверка: адрес `/exec`, открытый в браузере, показывает «работает».

## Что приходит

- Письмо после каждой тренировки: счёт, ошибки, темы для повторения и блок ПРОГРЕСС.
- В таблице листы «Сессии» (одна строка на тренировку), «Ответы» (каждый ответ) и «Прогресс» (последний блок ПРОГРЕСС).
- Файл «История — результаты.md» на Google Диске, в который дописывается каждая тренировка.

## Раздел «За родитеље»

Ссылка внизу главной страницы, PIN по умолчанию `1234` (его можно сменить там же). В разделе: статус и история ответов по каждому вопросу, загрузка другого банка для проверки, резервная копия и сброс прогресса.
Прогресс хранится в браузере телефона, на котором проходят тренировки.
